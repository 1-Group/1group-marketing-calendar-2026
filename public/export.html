The Marketing Calendar has moved to attribution.1-group.ai. Events you added here were saved in this browser only. Download them, then import them into the new calendar so everyone can see them.

Checking this browser…
  1. Open this page in the browser you used for the old calendar.
  2. Click Download my events.
  3. Go to the new calendar, click Import from old calendar and choose the file.

Importing never overwrites an event that is already in the new calendar, so it is safe for several people to import, or to import twice.
